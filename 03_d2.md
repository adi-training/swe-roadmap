# 1. C++ Language — Vectors, References, and File Input

## 1.1 What is `std::vector`?

An array is an ordered list of values. A `std::vector` is C++’s standard, flexible version of an array.

```cpp
#include <vector>

std::vector<int> numbers = {4, 7, 1, 9};
```

Visual model:

```text
Index:   0   1   2   3
Value:   4   7   1   9
```

Unlike a fixed-size array, a vector can grow:

```cpp
numbers.push_back(12);
```

Now it contains:

```text
[4, 7, 1, 9, 12]
```

## 1.2 Useful vector operations

| Code | Meaning | Typical complexity |
|---|---|---:|
| `numbers[0]` | Read the first value | O(1) |
| `numbers[2] = 10` | Change the third value | O(1) |
| `numbers.size()` | Number of values | O(1) |
| `numbers.empty()` | Is the vector empty? | O(1) |
| `numbers.push_back(5)` | Add a value to the end | O(1) amortized |
| `numbers.pop_back()` | Remove the final value | O(1) |
| Traverse all values | Visit every value | O(n) |

`numbers[0]` is valid only when the vector contains at least one value. Always check `numbers.empty()` before using the first element.

## 1.3 Two ways to traverse a vector

### Value loop

Use this when you need the value but not its index:

```cpp
for (int number : numbers) {
    std::cout << number << '\n';
}
```

### Index loop

Use this when you need the position:

```cpp
for (std::size_t index = 0; index < numbers.size(); ++index) {
    std::cout << "Index " << index
              << " has value " << numbers[index]
              << '\n';
}
```

`std::size_t` is an unsigned integer type used for sizes and indexes. It is the type returned by `numbers.size()`.

## 1.4 Pass-by-value versus pass-by-reference

When you call a function, C++ needs to know whether it should receive a **copy** or access the **original** value.

### Pass-by-value: make a copy

```cpp
void addOne(int number) {
    number += 1;
}
```

This is fine for small values such as `int`, `double`, and `bool`.

```text
Original number: 5
Function changes its own copy to 6
Original number remains 5
```

### Pass-by-reference: change the original

```cpp
void addOne(int& number) {
    number += 1;
}
```

`&` means “reference.” The function receives another name for the original value.

```text
Original number: 5
Function changes it to 6
Original number is now 6
```

### Constant reference: read the original but do not change it

```cpp
int calculateSum(const std::vector<int>& numbers) {
    // Can read numbers.
    // Cannot modify numbers.
}
```

This is the normal choice when a function reads a vector or string:

| Part | Meaning |
|---|---|
| `const` | The function promises not to change the vector |
| `&` | The function avoids copying the full vector |

## 1.5 Rule of thumb for parameters

| Situation | Parameter form |
|---|---|
| Read a small value | `int number` |
| Read a string/vector | `const std::string& text`, `const std::vector<int>& numbers` |
| Modify the caller’s vector | `std::vector<int>& numbers` |

## 1.6 Reading a file

To read a file, include:

```cpp
#include <fstream>
```

Open a file:

```cpp
std::ifstream inputFile(filePath);
```

Check that opening succeeded:

```cpp
if (!inputFile.is_open()) {
    std::cerr << "Error: could not open file.\n";
    return;
}
```

Read one line at a time:

```cpp
std::string line;

while (std::getline(inputFile, line)) {
    std::cout << line << '\n';
}
```

| Tool | Meaning |
|---|---|
| `std::ifstream` | Input file stream; it reads files |
| `std::getline` | Gets one full line at a time |
| `std::cerr` | Prints an error message |
| `is_open()` | Checks whether the file was opened |

# 2. DSA — Accumulators and In-Place Array Changes

## 2.1 Revision from Day 1

A one-pass array problem normally means:

```text
1. Create a variable that stores the current answer.
2. Visit each input value once.
3. Update the variable.
4. Return the final answer.
```

On Day 1, the current answer was the `largest` number seen so far.

Today, use the same idea for a running total.

## 2.2 The accumulator pattern

An **accumulator** is a variable that stores a result while you scan input.

| Problem | Accumulator |
|---|---|
| Sum values | `sum` |
| Count matching values | `count` |
| Find largest value | `largest` |
| Find smallest value | `smallest` |

Example:

```text
Input: [4, 7, 1, 9]

sum = 0
Read 4 → sum = 4
Read 7 → sum = 11
Read 1 → sum = 12
Read 9 → sum = 21
```

The input has four values and every value is read once:

```text
Time: O(n)
Extra space: O(1)
```

## 2.3 Integer division warning

In C++, dividing two integers removes the decimal part.

```cpp
int result = 21 / 4;
```

`result` becomes `5`, not `5.25`.

For an average, convert at least one side to `double`:

```cpp
double average = static_cast<double>(sum) / numbers.size();
```

## Optional DSA stretch — Move Zeroes

Problem:

```text
Input:  [0, 1, 0, 3, 12]
Output: [1, 3, 12, 0, 0]
```

Use two indexes:

```text
readIndex: looks at every value
writeIndex: tracks where the next non-zero value belongs
```

Key invariant:

> Every position before `writeIndex` contains a non-zero value in its correct relative order.

Reference solution:

```cpp
#include <utility>
#include <vector>

void moveZeroes(std::vector<int>& numbers) {
    int writeIndex = 0;

    for (int readIndex = 0;
         readIndex < static_cast<int>(numbers.size());
         ++readIndex) {
        if (numbers[readIndex] != 0) {
            std::swap(numbers[writeIndex], numbers[readIndex]);
            ++writeIndex;
        }
    }
}
```

Complexity:

```text
Time: O(n)
Extra space: O(1)
```

### Review answers

1. A variable that stores a result as an algorithm scans input.
2. The algorithm reads every one of the `n` input values once.
3. Integer division removes decimal values; casting produces decimal division.
4. The algorithm stores only a few variables regardless of input size.
5. It is the position where the next non-zero value should be placed.

### Interview explanation to practice aloud

> I use a running sum accumulator and scan each value once. I handle empty input before dividing, then convert the sum to `double` so the average keeps its decimal part. The algorithm is O(n) time and O(1) extra space.

```cpp
#include <fstream>
#include <iostream>
#include <string>
#include <vector>

void printWelcomeMessage() {
    std::cout << "Sensor Log Analyzer\n";
    std::cout << "Version: 0.2.0\n";
}

void analyzeFile(const std::string& filePath) {
    std::ifstream inputFile(filePath);

    if (!inputFile.is_open()) {
        std::cerr << "Error: Could not open file: "
                  << filePath
                  << '\n';
        return;
    }

    std::size_t lineCount = 0;
    std::vector<std::string> previewLines;
    std::string line;

    while (std::getline(inputFile, line)) {
        ++lineCount;

        if (previewLines.size() < 3) {
            previewLines.push_back(line);
        }
    }

    std::cout << "File opened successfully.\n";
    std::cout << "Total lines: " << lineCount << "\n\n";
    std::cout << "First " << previewLines.size() << " line(s):\n";

    for (const std::string& previewLine : previewLines) {
        std::cout << previewLine << '\n';
    }
}

int main(int argc, char* argv[]) {
    printWelcomeMessage();

    if (argc < 2) {
        std::cout << "Usage: ./log_analyzer <log-file-path>\n";
        return 0;
    }

    analyzeFile(argv[1]);

    return 0;
}
```

### Step 4: understand `analyzeFile`

| Code | Meaning |
|---|---|
| `std::ifstream inputFile(filePath)` | Attempts to open the file for reading |
| `if (!inputFile.is_open())` | Handles failure before processing |
| `lineCount` | Counts every line read |
| `previewLines` | Stores at most the first three lines |
| `while (std::getline(...))` | Continues until there are no more lines |
| `previewLines.size() < 3` | Prevents storing more than three preview lines |
