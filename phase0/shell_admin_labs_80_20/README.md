# Linux & Bash Administrative Mini-Projects

A 20-hour practical shell administration lab track made of ten approximately two-hour projects.

Each project simulates a realistic administrative task and follows:

**30 min build → 30 min test → 30 min improve → 30 min explain**

Open `00_toc.md` first. The `answers/` directory is intentionally separate so you can attempt the labs before seeing the solutions.
