# Chapter 9 — Python Capstone Practice Set

**Time:** ~70 minutes  
**Goal:** Solve mixed problems without being told which chapter or feature to use.

For each problem:

1. Restate it in your own words.
2. Write a small example.
3. Decide the data structure.
4. Write the simplest correct approach.
5. Estimate time/space complexity.
6. Code and test edge cases.

---

# Level 1 — Warm-up

## E1. Digit statistics

Given a positive integer, return the number of digits, digit sum, and reversed number.

## E2. Word statistics

Given a sentence, return word count, longest word, and number of distinct words.

## E3. Rotate list

Rotate a list right by `k` positions.

## E4. Merge two sorted lists

Return one sorted list containing all values from two sorted input lists.

# Level 2 — DSA warm-up

## E5. Valid palindrome

Check a string while ignoring case and non-alphanumeric characters.

## E6. First non-repeating character

Return the index of the first character whose frequency is one, or `-1`.

## E7. Intersection with counts

Given two lists, return common values respecting duplicate counts.

## E8. Missing number

Given numbers from `0` to `n` with one missing, find the missing value.

## E9. Longest increasing contiguous run

Return the length of the longest strictly increasing contiguous segment.

# Level 3 — DSA bridge

## E10. Subarray sum equals target

For an integer list and target, determine whether a contiguous subarray sums to target. Aim for O(n) when values can be negative.

## E11. Group anagrams

Group a list of strings so anagrams appear together.

## E12. Minimum window idea

Given strings `s` and `t`, return the shortest substring of `s` containing every character of `t` with multiplicity. A standard sliding-window approach is expected.

# Level 4 — Mini project

## E13. Command-line frequency analyzer

Write a script that accepts a text filename from `sys.argv`, reads the file, and prints:

- number of lines
- number of words
- number of non-space characters
- top five most frequent words, case-insensitive

Handle a missing filename and a missing file cleanly.
