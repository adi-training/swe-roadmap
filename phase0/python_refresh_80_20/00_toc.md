# Python 80:20 Refresh — Hands-On Roadmap

## Goal

This is an **8–10 hour practical Python refresher** for someone who has seen Python before and wants to rebuild confidence before DSA, scripting, automation, or coding interviews.

The emphasis is on the Python you will use repeatedly:

- variables and core types
- conditions and loops
- functions and scope
- lists, tuples, dictionaries, and sets
- strings
- file handling and exceptions
- classes and objects at a practical level
- comprehensions and useful built-ins
- DSA-friendly Python patterns such as sorting, hashing, stacks, queues, and two pointers

Advanced topics such as decorators, generators in depth, async programming, type-system internals, packaging, metaclasses, and framework-specific Python are intentionally postponed.

## How to use these files

For every chapter:

1. Read the explanation quickly.
2. Type the examples yourself.
3. Solve every hands-on exercise before opening the answer key.
4. Run the program after small changes.
5. Test normal cases, empty/small cases, and unusual input.
6. Move on when the syntax feels natural rather than memorized.

A useful 80:20 rule is: **understand the core idea, write it from memory, then solve a small problem with it.**

## Environment

Use Python 3.11+ if possible.

```bash
python3 --version
python3 program.py
```

For quick experiments:

```bash
python3
```

## DSA readiness checklist

By the end, you should be able to:

- write and call functions without looking up syntax
- traverse a list/string confidently
- use `dict` and `set` for frequency/counting/membership problems
- sort with `sorted()` and `.sort()`
- use `deque` for queue/BFS-style problems
- use a list as a stack
- read and write files safely
- understand mutable vs immutable objects at a practical level
- state approximate time complexity for your solution
