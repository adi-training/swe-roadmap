# 1. C++ Language — Headers, Source Files, Namespaces, and Structs

## 1.1 Why split C++ into multiple files?

Small programs can place everything inside `main.cpp`. Larger programs become difficult to read and maintain if every function, data type, and feature is in one file.

Instead, separate the project by responsibility:

```text
include/         Declarations: what the program can do
src/             Definitions: how the program does it
src/main.cpp     Starts and coordinates the program
```

Example:

```text
include/log_parser.hpp  says: “A function can parse a log line.”
src/log_parser.cpp      contains: “Here is how parsing works.”
src/main.cpp            calls the parser and prints results.
```

## 1.2 Header files (`.hpp`)

A header contains **declarations**. A declaration tells other files a function or data type exists.

```cpp
// log_parser.hpp
bool parseLogLine(const std::string& line, LogEntry& entry);
```

This tells C++:

> There is a function named `parseLogLine`. It receives a line of text and a log entry to fill. It returns `true` or `false`.

The header does not explain the full parsing algorithm. That belongs in the source file.

## 1.3 Source files (`.cpp`)

A source file contains **definitions**: the actual function code.

```cpp
// log_parser.cpp
bool parseLogLine(const std::string& line, LogEntry& entry) {
    // Actual parsing logic lives here.
}
```

The declaration and definition must agree exactly: same function name, parameter types, and return type.

## 1.4 What is `#pragma once`?

At the top of a header file you will write:

```cpp
#pragma once
```

It means:

> Include this header only once while compiling each source file.

Without it, a header accidentally included more than once can cause “redefinition” errors.

## 1.5 What is a namespace?

A namespace groups related names and prevents naming conflicts.

```cpp
namespace log_analyzer {
    void printSummary();
}
```

Call the function outside the namespace:

```cpp
log_analyzer::printSummary();
```

Think of it as a folder for names:

```text
log_analyzer::parseLogLine
```

means “the `parseLogLine` function in the `log_analyzer` group.”

## 1.6 What is a `struct`?

A struct groups related values into one custom data type.

```cpp
struct LogEntry {
    std::string timestamp;
    std::string level;
    std::string message;
};
```

One log entry then looks like:

```text
timestamp: 2026-09-20 10:00:01
level:     INFO
message:   Temperature sensor started
```

Create and access a struct:

```cpp
LogEntry entry;
entry.timestamp = "2026-09-20 10:00:01";
entry.level = "INFO";
entry.message = "Temperature sensor started";
```

## 1.7 Basic error handling with `bool`

A parsing function may fail because a line is malformed. One simple approach is to return `bool`:

```cpp
bool parseLogLine(const std::string& line, LogEntry& entry);
```

```text
true  → parsing succeeded; entry contains valid data
false → parsing failed; caller should handle the bad line
```

This is useful because the caller decides what to do: skip the bad line, print a warning, or stop the program.

# 2. DSA — Prefix Sums

## 2.1 Why do we need prefix sums?

Suppose an array represents readings:

```text
Index:   0  1  2  3  4
Value:   2  5  1  3  4
```

Question:

```text
What is the sum from index 1 through index 3?
5 + 1 + 3 = 9
```

For one query, scanning that range is fine. But if there are many range-sum questions, repeatedly scanning becomes slow.

## 2.2 Build a prefix-sum array

Create an extra array where each position stores the sum of all values before it.

Use a leading zero:

```text
Values:  [2, 5, 1, 3, 4]
Prefix:  [0, 2, 7, 8, 11, 15]
Index:    0  1  2  3   4   5
```

Meaning:

```text
prefix[0] = sum of zero values = 0
prefix[1] = 2
prefix[2] = 2 + 5 = 7
prefix[3] = 2 + 5 + 1 = 8
```

## 2.3 Answer a range query

For inclusive range `left` through `right`:

```text
rangeSum = prefix[right + 1] - prefix[left]
```

Example: sum from index `1` through `3`:

```text
prefix[4] - prefix[1]
11 - 2
= 9
```

Why it works:

```text
prefix[4] includes values at indices 0, 1, 2, 3
prefix[1] includes only value at index 0

Subtracting removes everything before index 1.
```

## 2.4 Complexity

| Work | Complexity |
|---|---:|
| Build prefix array once | O(n) time and O(n) space |
| Answer each valid range query | O(1) time |

Prefix sums trade extra memory and one setup pass for fast repeated queries.

```cpp
#include <iostream>
#include <vector>

std::vector<int> buildPrefixSums(const std::vector<int>& values) {
    std::vector<int> prefixSums;
    prefixSums.push_back(0);

    for (int value : values) {
        int nextSum = prefixSums.back() + value;
        prefixSums.push_back(nextSum);
    }

    return prefixSums;
}

int rangeSum(
    const std::vector<int>& prefixSums,
    int left,
    int right
) {
    return prefixSums[right + 1] - prefixSums[left];
}

int main() {
    std::vector<int> values = {2, 5, 1, 3, 4};
    std::vector<int> prefixSums = buildPrefixSums(values);

    std::cout << "Sum from index 1 through 3: "
              << rangeSum(prefixSums, 1, 3)
              << '\n';
}
```

### Interview explanation to practice aloud

> I preprocess the array into prefix sums, where each entry stores the sum of all values before that position. For an inclusive range, I subtract the prefix before the left boundary from the prefix after the right boundary. Building takes O(n) time and O(n) space, while each range query is O(1).

# 3. Project — Parse Simple CSV Log Rows

## 3.1 What is CSV?

CSV means **comma-separated values**. Each line contains fields separated by commas.

Example:

```text
2026-09-20 10:00:01,INFO,Temperature sensor started
```

This project uses exactly three fields:

```text
timestamp,level,message
```

Important limitation for today: the message cannot contain a comma. Full CSV rules are more complicated and are outside Day 3’s scope.

```cpp
#include "log_parser.hpp"

#include <sstream>
#include <string>

namespace log_analyzer {
    bool parseLogLine(const std::string& line, LogEntry& entry) {
        std::stringstream lineStream(line);

        std::string timestamp;
        std::string level;
        std::string message;

        if (!std::getline(lineStream, timestamp, ',') ||
            !std::getline(lineStream, level, ',') ||
            !std::getline(lineStream, message)) {
            return false;
        }

        if (timestamp.empty() || level.empty() || message.empty()) {
            return false;
        }

        entry.timestamp = timestamp;
        entry.level = level;
        entry.message = message;

        return true;
    }
}
```

How it works:

| Code | Meaning |
|---|---|
| `std::stringstream lineStream(line)` | Lets the program read from the line as if it were a small input file |
| `std::getline(..., ',')` | Reads text until the next comma |
| `std::getline(lineStream, message)` | Reads the remaining text as the message |
| `return false` | Tells `main.cpp` that the line is malformed |
| `entry.timestamp = timestamp` | Copies valid parsed text into the output record |

### Step 6: replace `src/main.cpp`

Replace its full contents with:

```cpp
#include <fstream>
#include <iostream>
#include <string>
#include <vector>

#include "log_entry.hpp"
#include "log_parser.hpp"

void printWelcomeMessage() {
    std::cout << "Sensor Log Analyzer\n";
    std::cout << "Version: 0.3.0\n";
}

void printEntry(const log_analyzer::LogEntry& entry) {
    std::cout << '[' << entry.timestamp << "] "
              << entry.level << ": "
              << entry.message << '\n';
}

void analyzeFile(const std::string& filePath) {
    std::ifstream inputFile(filePath);

    if (!inputFile.is_open()) {
        std::cerr << "Error: Could not open file: "
                  << filePath
                  << '\n';
        return;
    }

    std::vector<log_analyzer::LogEntry> entries;
    std::string line;
    std::size_t lineNumber = 0;
    std::size_t invalidLineCount = 0;

    while (std::getline(inputFile, line)) {
        ++lineNumber;

        log_analyzer::LogEntry entry;

        if (log_analyzer::parseLogLine(line, entry)) {
            entries.push_back(entry);
        } else {
            ++invalidLineCount;
            std::cerr << "Warning: Skipping invalid line "
                      << lineNumber
                      << '\n';
        }
    }

    std::cout << "Valid entries: " << entries.size() << '\n';
    std::cout << "Invalid entries: " << invalidLineCount << "\n\n";
    std::cout << "Parsed entries:\n";

    for (const log_analyzer::LogEntry& entry : entries) {
        printEntry(entry);
    }
}

int main(int argc, char* argv[]) {
    printWelcomeMessage();

    if (argc < 2) {
        std::cout << "Usage: ./log_analyzer <log-file-path>\n";
        return 0;
    }

    analyzeFile(argv[1]);

    return 0;
}
```
